## Findings resolved

- The original control outline did not reach 3:1 against grapefruit. It now uses `#496453`; semantic text and control-boundary contrast tests pass.
- Flutter's default chip label faded long text at large scale. Enabling wrapping alone exposed vertical clipping because RawChip's checkmark slot grew with label height. The checkmark now has a bounded size inside the measured label. Native FilterChip selection semantics remain. A regression with real fonts at 320px/3× text checks each text box's right and bottom bounds; it failed before the fix and passes after it.
- Loading real fonts revealed faint 14-pixel captions in the rendered contrast check. The small-caption weight is now 600; the full gallery and modal pass Flutter's text-contrast guideline.
- Golden-test setup initially omitted Material Icons. The setup now loads all three font families; the final images were visually checked for actual glyphs.
- Keyboard tests now verify repeated Tab traversal remains within the modal, Escape returns focus to its opener, and the close action remains reachable above a keyboard inset.
