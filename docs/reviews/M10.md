# M10 review — Home-bar inventory and shopping list

**Date:** 2026-09-14  
**Reviewer:** Fresh Codex Terra subagent, separate from the three implementation tracks.  
**Scope:** Backend schema, validation, routes, ownership and revisions; Drift schema 5 and local repository; HTTP and sync engines; account coordinator; persistent and scoped bar routes; recipe/shopping actions; tests and goldens.  
**Verdict:** APPROVE after fixes. No blocking or major findings remain.

## Findings and resolutions

| # | Severity | Finding | Resolution |
| --- | --- | --- | --- |
| 1 | Blocker | An accepted PUT response could overwrite a newer local move made while that request was in flight, then clear `dirty`, silently losing the move. | Server push results now use an atomic compare-and-apply in the Drift transaction. Every client-authoritative field must still match the sent snapshot before the response can clear `dirty`. Pull application also uses an atomic priority check. A delayed-PUT regression preserves the newer move. |
| 2 | Major | If the local-write debounce expired during that slow PUT, it joined the active pass; after the atomic guard preserved the newer dirty row, no pass remained scheduled to upload it. | `HomeBarSyncEngine` records one trailing-pass request while a pass is active and starts it when that pass completes. Sign-out cancels the timer and pending pass before the final push. The regression now lets the debounce expire before releasing the response and verifies the move reaches the server without a manual `syncNow`. |
| 3 | Major, integrator review | Recipe detail treated a loading inventory as empty, briefly offering to add every essential to shopping; using it could move an already stocked ingredient to shopping. | The recipe action now waits for inventory, exposes a retryable error state, and does not offer the write until stocked identities are known. A widget regression covers the loading guard and verifies only unstocked essentials are added. |
| 4 | Test gap | `/bar/shopping` had an initial-route golden but no explicit nested-route Back assertion. | A widget test enters Shopping from My bar, verifies the URL, pops, and confirms return to the shelf. |
