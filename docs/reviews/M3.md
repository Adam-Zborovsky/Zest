Adam approved M3 discovery/detail and the composed-skills path, with a Terra subagent. The main agent retained design, architecture and routing. ## Findings and regressions closed

1. **Form reset lost the user's text.** Flutter's field reset restored its initial value after a routed query was assigned, and mode changes also cleared drafts. The regression failed with expected `Draft botanical`, actual empty text. Reset now precedes restoring the intended query/draft; sequential submissions, mode changes and Back preserve it.
2. **Keyboard submission escaped the route focus scope.** Unfocusing the whole route put focus outside the app's shortcuts. Unfocusing the field keeps keyboard traversal operational. A pointer-free search/result activation test passes.
3. **Alphabet expansion collided with scroll state.** A generic key let the expansion widget read the scroll offset as a Boolean. Its dedicated `PageStorageKey` separates expansion state from the scroll position; ingredient-to-letter browsing now passes.
4. **Rate limits could be shortened or extended incorrectly.** Overlapping responses now preserve the longest cooldown. The gateway provides an absolute `retryAt` deadline and the UI derives remaining time from its injectable clock. A regression first failed when a foreground tick did not account for elapsed background time; expiry and remount now pass. Retry is explicit and implicit provider retries are disabled.
5. **Outcome announcements and destination names were incomplete.** Empty/rate-limit outcomes now announce their titles separately from controls/countdowns. Native button text semantics distinguish `View recipe: <name>` without changing visual labels. The previous indistinguishable-name assertion was confirmed failing before the fix.
6. **Image state coverage was missing.** Added in-memory synthetic loading/success/failure tests and HTTPS/credential validation checks. Fallback captions are visible, grow outside the fixed image area, and do not falsely credit original placeholder artwork as provider photography. Null images remain intentionally designed.
